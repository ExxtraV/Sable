Sable / Privacy

Privacy

The short version: your writing stays on your Mac, there are no accounts, and this website doesn’t track you.

This page is written by Claude Code.

The app

  • Your writing stays yours. Sable reads and saves ordinary files in the folders you choose. It doesn’t upload, copy, or analyze your writing on any server.
  • No account. There’s nothing to sign up for.
  • On-device tools. Prose suggestions use a word list stored on your Mac. Sentence coloring and spell checking use tools built into macOS.
  • Sync is up to you. If you keep your writing folder in iCloud Drive, Dropbox, or OneDrive, that service’s own privacy policy applies to those files.
  • Update checks. When automatic checks are on, the app asks for a small update file hosted on GitHub. GitHub can see the request, as with any download from its servers. Sable doesn’t add system profile information to that request.

This website

  • No analytics, advertising, or tracking scripts, and no cookies set by this site.
  • The site is hosted on Vercel, which may keep standard server logs, such as IP addresses, for security and operations.
  • The download button asks GitHub (api.github.com) which release is newest, so your browser contacts GitHub when the page loads. Nothing is sent about you beyond what any web request includes.
  • Links to GitHub and to Buy Me a Coffee (the Support Sable link) lead to other sites with their own policies.

Open source

You don’t have to take our word for it. Sable is open source, and you can read exactly what it does in the source code. Questions or concerns? Open an issue.
