First launch

Opening Sable for the first time

Sable is signed for updates but isn’t notarized by Apple, which needs a paid developer membership, so macOS asks you to approve it once. It takes about a minute, and you only do it the first time.

StepWhat you’ll seeWhat to do
1Open Sable from your Applications folder. macOS says it “can’t be opened” or that Apple couldn’t check it for malware.Click Done. Don’t choose “Move to Bin”.
2Open System Settings → Privacy & Security and scroll down to the Security section. It says “Sable Markdown Writer” was blocked.Click Open Anyway.
3macOS asks once more and may want your password or Touch ID.Confirm, then click Open.
4Sable opens and asks you to choose or create a writing folder.From now on it opens like any other app. Updates arrive inside Sable, verified with the project’s signing key.

On macOS 14 you can also Control-click the app and choose Open, then Open again. Prefer Terminal? xattr -dr com.apple.quarantine "/Applications/Sable Markdown Writer.app" does the same thing. Only do this for a download from this page or the GitHub releases.
