Our goal is to continue to provide more tools and continued support, while maintaining our commitment to focus and creating a distraction-mitigating environment.

No Account. No Collection. No Proprietary Files. All Markdown. All Yours. All Local.

No AI Integration

Sable will never directly integrate AI into the program. We encourage you to put your prose on the page, and focus on improving your craft. Writing requires practice and challenge to learn and grow, which you won’t get from having a robot write for you.

Questions

How much does Sable cost?

Free, and always so. Sable will remain free and open source.

Does Sable lock my writing into a proprietary format?

No, all written files are Markdown files, which can be opened by any other markdown editor or program that supports markdown.

Will you release a Windows version?

A Windows port is not currently in the works.

Who is Sable for?

Anybody who writes and prefers a clutter-free and focused workspace. Sable is designed to be a great markdown editor first and foremost, with a suite of features for fiction writers on top.

Does Sable sync with other devices?

Sable does not operate a cloud service, but you can connect your writing folder to your preferred cloud provider (iCloud, Dropbox, etc.) to sync your files across devices.

Is Sable on the App Store? Will it support iOS or iPadOS?

Sable is currently unnotarized by Apple, which requires us to pay $99 a year to be notarized. If we pursue that route, we might opt for an App Store release in continued development on other devices.

Opening Sable for the first time

Instructions from Claude: Sable is signed for updates but isn’t notarized by Apple, which needs a paid developer membership, so macOS asks you to approve it once. It takes about a minute, and you only do it the first time.

StepWhat you’ll seeWhat to do
1Open Sable from your Applications folder. macOS says it “can’t be opened” or that Apple couldn’t check it for malware.Click Done. Don’t choose “Move to Bin”.
2Open System Settings → Privacy & Security and scroll down to the Security section. It says “Sable Markdown Writer” was blocked.Click Open Anyway.
3macOS asks once more and may want your password or Touch ID.Confirm, then click Open.
4Sable opens and asks you to choose or create a writing folder.From now on it opens like any other app. Updates arrive inside Sable, verified with the project’s signing key.

On macOS 14 you can also Control-click the app and choose Open, then Open again. Prefer Terminal? xattr -dr com.apple.quarantine "/Applications/Sable Markdown Writer.app" does the same thing. Only do this for a download from this page or the GitHub releases.
