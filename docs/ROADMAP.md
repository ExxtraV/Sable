# New Quill roadmap

First priority: a dependable, minimalist Markdown editor with safe saves, accessible shortcuts, calm themes, and ordinary files users control.

## Later: Fiction Projects

Create a named project folder containing Manuscripts, Characters, Background, and World documents. Keep these as regular folders and Markdown files. Users choose what headings mean (chapters, scenes, or episodes). Do not require a project to edit a standalone file.

## Later: Export

PDF, EPUB, and other manuscript formats, with a preview and explicit export settings.
